### Reference payloads (illustrative)

The cross-border and local ePrescription/eDispensation sample Bundles, the IE→DE CDA ePrescription and a Postman
collection are in the source repository under `input/examples/` and `input/postman/`. Each is described, with its
scenario, on [Sample Payloads & Downloads](crossborder-sample-payloads.html). They are reference examples ported from
IE Core 0.2.0; all data is fictional.

The package is not yet published to the FHIR package registry or Simplifier.net. See
[Simplifier Publishing](simplifier-publishing.html).
