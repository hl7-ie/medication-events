# HL7 Ireland Medication Events

This implementation guide is the starter publication space for Irish medication-event interoperability.

## Initial focus

- medication prescribing and updates using `MedicationRequest`
- medication administration and event reporting using `Observation`
- linkage to Patient and Encounter context
- support for Irish ePrescription and NePS-aligned workflows

The current guide is intentionally lightweight and is designed to be extended with national governance, terminology, and workflow requirements over time.
